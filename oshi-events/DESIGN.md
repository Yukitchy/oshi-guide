## 実体はスキル1本（サイトを増やさない）
```
~/.claude/skills/oshi-events/
  SKILL.md          # engine: 手順。固有名詞・ユウキのパスを書かない
  sources.json      # pack: イベント情報源（下記）＋検索クエリ雛形
  template.html     # pack: 出力1枚のガワ
```
OshiGuide本体（index/app/inquiry）は触らない。将来 `inquiry.html` の相談が来たらこのスキルで返す、という接続。

## 入力（最小2つ）
必須: ①好きな作品（複数可・英題/略称OK） ②来日期間（開始〜終了）
任意: 滞在拠点 / 人数・年齢 / 予算 / 既に決まってる予定

## 手順
1. **作品を正規化** — 英題・日本語題・略称・公式ローマ字を全部そろえる（ここを外すと検索が全部空振りする）
2. **sources.json の情報源を期間で当てる** — カテゴリごとに固定クエリでWebSearch。都度検索なので情報源リストだけ手動で育てる
3. **実在確認（必須）** — 公式サイトを開いて「①会期に来日期間が重なる ②会場住所 ③チケット要否」の3点を確認。確認できないものは載せない（akiba-tour-shiori と同じ鉄則。過去に架空スポット4件事故）
4. **期間内に収まるものだけ残して日付順に並べる**
5. **チケット取得難易度を3色で判定** ← ここが本体
   - 🟢 当日フラッと行ける（入場無料の展示・常設・コラボカフェの当日枠）
   - 🟡 事前予約が要る（Web予約・Claudeが代行できる）
   - 🔴 抽選 / 国内クレカ・日本の住所 / 既に完売（ゲスト単独では取れない＝ユウキ1手 か 諦めを明言）
6. **空いた日を常設の聖地で埋める** — OshiGuide名鑑と秋葉原定番スポット素材集から

## 出力（1枚HTML＋送れる文面）
1. 来日期間のカレンダー（日付 × 入るイベント）
2. イベントカード: 写真 / 会期 / 会場 / 🟢🟡🔴 / 公式URL / 「なぜあなた向けか」1行
3. イベントが無い日の常設案
4. **そのまま送れる英文提案（和訳併記）**
5. **ユウキの1手リスト** — 🔴と🟡のうち人が動くぶんだけ抜き出す

## やらないこと
- イベント情報の自動巡回・DB化（都度WebSearchで足りる。台帳が要るほど回数が出てから）
- 決済・予約の代行（OshiGuideの「決済を持たない」方針どおり）
- 常駐・通知（呼ばれた時だけ動くプル型）

## 完成の定義
ユウキ以外のゲスト1組にこれで出したプランから、実際に1件イベント予約が成立した。
